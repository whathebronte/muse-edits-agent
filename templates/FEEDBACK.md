# Feedback log

Every piece of creator feedback, in the creator's own words, with the rule distilled from it and where that rule now lives. Entries never expire when the rubric version changes.

## Format

### [Date] · [Set or job name]

- **Creator said:** "[verbatim feedback]"
- **Rule distilled:** [the standing rule this creates or changes]
- **Now lives in:** [system file section / learnings checklist item / charter line]
- **Reviewer agreement:** [agreed / disagreed / not reviewed, and any rubric recalibration made]
